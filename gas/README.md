# Google ドライブへの保存（受け取り用スクリプト）の設定手順

子どもが「3Dプリントに おくる」を押すと、STL ファイルが Google ドライブのフォルダに保存されるようにする手順です。
設定は講師が一度だけ行います。

> **使うアカウント**: 個人の Gmail アカウントで作成してください。Google Workspace の組織アカウント（学校・団体のアカウント）では、組織の設定によって外部からアクセスできず、つながらないことがあります。
> フォルダとスクリプトは **同じアカウント** で作ってください。子どもの端末ではログインは不要で、端末に保存されるのは受け取り用のURLだけです。

## 1. 保存先のフォルダを作る

1. Google ドライブで、STL を集めるフォルダを作る（例: `3Dプリント受付`）
2. フォルダを開き、ブラウザのアドレス欄の最後の部分（`https://drive.google.com/drive/folders/` の後ろ）をコピーする
   これが **フォルダID** です

## 2. 受け取り用スクリプトを作る

1. https://script.google.com を開き、「新しいプロジェクト」を作る
2. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の中身を貼り付ける
3. 5行目あたりの `const FOLDER_ID = 'ここにフォルダIDを入れる';` に、手順1のフォルダIDを入れる
4. 保存する（プロジェクト名は自由。例: `かたちづくり受付`）

## 3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車）で「ウェブアプリ」を選ぶ
3. 次のように設定して「デプロイ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 初回は「アクセスを承認」を求められるので、自分のアカウントで許可する
   （「このアプリは確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーする

## 4. ツールに設定する（各端末で1回）

1. ツールの画面右下の歯車を **2秒間長押し** する
2. 「Google ドライブ（受け取り用URL）」を選び、手順3のURLを貼り付ける
3. 「つながるか確認」を押し、「つながりました」と出ることを確かめて「保存」

## 5. 制御用PCで受け取る

- ブラウザで手順1のフォルダを開けば、送られた STL が並びます
- 「Google ドライブ パソコン版」を入れておくと、フォルダが自動でPCに同期されるので、スライサーから直接開けます
- ファイル名は `sakuhin-年月日-時分秒-番号.stl` です。番号は送信後に子どもの画面に大きく表示されます

## つながらないときは

| 症状 | 原因 | 対処 |
|---|---|---|
| 「つながりませんでした」、URLが `…/d/…/edit` の形 | スクリプトの編集画面のURLを貼っている | 「デプロイを管理」に出る `…/macros/s/…/exec` のURLを使う |
| `…/exec?ping=1` を開くと「アクセス権が必要です」 | 「次のユーザーとして実行」が「アクセスしているユーザー」、または「アクセスできるユーザー」が「自分のみ」 | 「次のユーザーとして実行」を「自分」、「アクセスできるユーザー」を「全員」に変更して再デプロイ |
| 同上（設定は正しい） | 組織アカウントの制限、またはブラウザで別アカウントにログインしている | 個人の Gmail アカウントで作り直す。確認はシークレットウィンドウで行う |
| 「スクリプト関数が見つかりません」 | Code.gs を保存する前にデプロイした | 保存してから「デプロイを管理」→ 編集 → 新バージョンでデプロイ |
| つながるが保存されない | フォルダIDの誤り、またはフォルダへの権限がない | エディタで確認用の関数を実行してフォルダ名が出るか確かめる（下記） |

確認用の関数（Code.gs の最後に貼り、エディタで `testFolder` を実行）:

```javascript
function testFolder() {
  const folder = DriveApp.getFolderById(FOLDER_ID);
  Logger.log('保存先フォルダ: ' + folder.getName());
}
```

スクリプトを書き換えたときは、保存だけでなく「デプロイを管理」→ 編集 →「新バージョン」でデプロイし直してください。

## ワークショップが終わったら

- 「デプロイ」→「デプロイを管理」→ 該当のデプロイを「アーカイブ」すると、URLが使えなくなります
- 次回は「新しいデプロイ」でURLを発行し直してください（URLが変わるので、各端末の設定もやり直します）

## 安全のための制限（Code.gs で実施）

- 受け付けるのは、ツールが作る形式のファイル名（英数字とハイフン + `.stl`）だけ
- バイナリSTLの形になっていないデータ、20MBを超えるデータは受け付けない
- 保存先は指定したフォルダ1つだけ

受け取り用URLを知っている人は誰でもこのフォルダにSTLを送れるので、URLは参加者以外に公開しないでください。
